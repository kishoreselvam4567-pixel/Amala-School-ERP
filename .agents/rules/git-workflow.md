# Git Workflow Rules

1. **Local-Only Execution**: Run and test all commands, scripts, builds, and edits on the local environment first.
2. **Disable Automatic Pushes**: Never automatically execute `git push` to GitHub or remote repositories under any circumstances.
3. **Manual Confirmation**: Always require explicit manual confirmation from the user prior to performing a remote push.
4. **Verification & Success Check**: Provide a clear success check report of the local verification before asking to push.
